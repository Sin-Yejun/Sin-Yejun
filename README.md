## 대표 프로젝트

### 번핏 AI 기능 (실무)

피트니스 앱 '번핏'에서 AI 제품 기능을 설계하고 개발했습니다. 추천 로직과 AI 파이프라인부터 백엔드, 앱 클라이언트, 배포까지 제품 개발 전반을 담당했습니다.

- **개인화 데일리 운동 추천** - 중량과 세트 수는 규칙 기반 로직으로, 운동 종목 구성은 LLM으로 처리하는 하이브리드 구조로 개발했습니다. 월 1만 명 규모가 이용하고, 추천 루틴을 시작한 사용자의 약 60%가 운동 완료까지 도달합니다.
- **AI 식단 기록 자동화** - 텍스트와 음식 사진을 LLM 멀티모달로 해석해 식단을 자동 기록하는 기능을 개발했습니다. 출시 후 월 식단 기록 사용자가 약 7-8배 늘었고, 전체 식단 입력의 90% 이상이 AI 기능으로 이뤄집니다.
- **AI 머신 스캐너** - Vision API와 400개 운동 데이터의 임베딩 검색을 결합한 헬스장 머신 인식 기능으로, 월 수천 회 사용됩니다.
- **CS 자동화 시스템** - 12개 언어로 들어오는 고객 문의의 번역, 분류, 답변 초안을 자동화하고 담당자가 검토 후 발송하는 사내 시스템을 구축했습니다. 운영 기간 동안 들어온 문의를 미처리 없이 전량 대응했습니다.

### 설교노트 AI (개인 프로젝트, 출시)

설교를 들으며 작성한 기록을 다시 읽고 묵상할 수 있도록 만든 Android 앱입니다. 오프라인 성경 검색과 노트 작성, AI 요약과 묵상 질문, 클라우드 백업을 제공합니다. 기획부터 개발, 스토어 출시까지 직접 진행했고, 광고 없이 활성 기기 약 100대 규모로 꾸준히 쓰이고 있습니다.

[개발 과정과 서비스 소개](https://github.com/Sin-Yejun/sermon-note-showcase) | [Google Play](https://play.google.com/store/apps/details?id=com.sermonnote.app)

### ETF Tracker (개인 프로젝트, 운영 중)

국내 액티브 ETF의 매일 공시를 자동으로 수집해 보유종목 변동을 텔레그램으로 알려주고 대시보드로 보여주는 자동화 프로젝트입니다. 서버 없이 GitHub Actions만으로 매일 운영하고 있습니다.

[저장소](https://github.com/Sin-Yejun/etf-tracker) | [대시보드](https://sin-yejun.github.io/etf-tracker/)
